Компания по продаже цемента решила провести акцию для своих клиентов. Самые быстрые покупатели могут купить любое количество цемента со скидкой, но после каждой покупки скидка уменьшается на 5%. Стартовая скидка составляет 50%. Цена за 50 кг цемента — 500 рублей.

Например, клиент "A" был самым первым и оформил заказ на 2000 кг цемента со скидкой 50%. Клиент "B" был вторым и оформил заказ на 1000 кг цемента, но скидка уже составила 45%.

Примеры заказов (время подачи заказа, название компании и количество покупаемого цемента) хранятся в текстовых файлах во вложении (вложение находится в самом низу страницы).

Необходимо посчитать конечную стоимость заказов для каждого клиента в формате <название компании> - <стоимость>. Результат следует сохранять в файл.

Во вложении 2 типа файлов. Один с расширением ".txt" и разделителем "|", а второй без расширения и разделителем "#". Необходимо предусмотреть поддержку обоих типов файлов с использованием интерфейсов и паттерна проектирования Адаптер.

Необходимо по максимуму использовать Stream Api.
